# SkyEar add-on for Home Assistant

Security cameras already have microphones. SkyEar listens to one, detects
aircraft, and checks every detection against live ADS-B.

## Install

Settings → Add-ons → Add-on Store → ⋮ → **Repositories**, then add:

```
https://github.com/MrUnluckyy/skyear-hassio
```

Install **SkyEar**, start it, and open it from the sidebar. Setup happens on
that page — there is no address to find and no port to open.
